\section{Software Synthesis Flow}
In the figure~\ref{fig:Software_Synthesis_Flow}, it is shown that the software synthesis takes a high-level model of a system and automatically generates the low-level embedded code, drivers, and binaries needed to run on a processor. It is, thus, eliminating the need for hard-coding, shortening the development time, reducing error-susceptibility, and allowing testing even before the real hardware is built — by using virtual platforms with instruction set simulators.
