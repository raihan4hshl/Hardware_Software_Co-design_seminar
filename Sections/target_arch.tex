\section{Target Architecture}
Software synthesis typically targets a multi-core embedded platform instead of single processor. These platforms have several general-purpose processors and hardware accelerators, each with its own local memory, programmable interrupt controller (PIC), and timer for time-based tasks.

Processors are connected to the system through a processor bus, enabling communication with local components, memories etc.
